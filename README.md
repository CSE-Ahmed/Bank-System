This is my first project using the fundamentals of C++. The project is a Bank System where you can perform the following operations:

1. Show Client List
2. Add Clients
3. Update Clients
4. Delete Clients
5. Search for a Client
6. Make Transactions
7. Manage Users

You can also add multiple users to manage this system and assign specific permissions to each. For example, you can grant a user access to add and update clients, while restricting their ability to delete clients or make transactions.

**What I used in this code:**
<fstream> Library
* Vectors
* Strings
* Enums
* Structures
* Bitwise operators

**What I learned from this project:**
* How to use the `<fstream>` library effectively, specifically understanding when to use `ios::out`, `ios::in`, and `ios::app`.
* How to handle various data types.
* How to determine when a function should be `void` and when it should return a specific data type.
